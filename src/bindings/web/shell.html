对每一块能被请求到的 GPU（auto / high-performance / low-power / software fallback， 浏览器无法枚举适配器，这就是全部可请求项）执行：CPU SIMD 参考 + 同一份 WGSL kernel， 再逐个比较 1,048,576 个 f32（位精确）。只有 GPU add: MATCH 才算通过。 第三列是 C ABI 侧自己请求到的适配器身份，用来确认它和 JS 侧枚举的不是两块不同的卡 （混合显卡上默认偏好可能落到 iGPU；见 docs/zig-gpu-spike.md §5）。 GPU add 列是单次端到端耗时（含管线创建、上传、dispatch、回读），只用于量级比较， 不是稳态基准；想比性能请用 native CLI（--adapter / --kernel chain）。 最后一次 run 的状态显示在顶部，全量结果在下表。
